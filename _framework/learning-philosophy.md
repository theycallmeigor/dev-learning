# Learning Philosophy — B+C Hybrid

## The approach

Every concept has two parts:

- **B (Foundation):** Understand the concept before touching it. The "why." No magic.
- **C (Project):** Immediately apply it to the running project. The "build."

You never study a concept in isolation. You understand it, then you use it. The project is the record.

## The atom format

A **learning atom** is one complete unit of work. It has three parts:

1. **Concept** — one thing explained (the B layer)
2. **Action** — one thing you do with it (the C layer)
3. **Interview line** — one sentence you could say about it tomorrow

Each atom takes 20 minutes or less. You can pick one up cold after a week away — no momentum required.

See `atom-format.md` for the template.

## The anchor project

Everything gets built on one running project. Each atom adds one brick. The project accumulates across sessions — you don't restart, you continue.

The commit history is the proof of work. By the end, someone can open GitHub and watch you build it layer by layer.

## What this is not

- Not a course. No video lectures, no quizzes.
- Not a tutorial. You're not following someone else's code — you're writing yours with AI assistance while understanding every piece.
- Not linear. If you get stuck on an atom, skip it and come back. The project still moves forward.
