# Bug Log

Every error you hit gets logged here. Same errors recur — grep this file before asking for help.

## Format

```
### YYYY-MM-DD — <one-line summary>

**Context:** what you were doing (which atom, which file)
**Error (exact):** paste the error message verbatim
**Cause:** what was actually wrong (filled in once you understand)
**Fix:** the change that resolved it
**Lesson:** what to do differently next time (optional)
```
